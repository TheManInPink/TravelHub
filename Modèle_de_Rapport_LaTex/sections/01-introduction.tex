\section{Introduction}
\label{sec:introduction}
%========================================================================================

\subsection{Contexte}

TravelHub est une plateforme de planification de voyages collaboratifs. Un utilisateur crée un voyage, le découpe en destinations, puis planifie des activités à chaque étape. Il peut partager le voyage avec d'autres utilisateurs, à qui il attribue un rôle : propriétaire, éditeur ou lecteur. Chaque destination est enrichie de données externes : la météo du séjour et une fiche descriptive du pays.

Ce rapport présente le back-end réalisé pour le premier travail pratique. Il décrit les choix techniques, l'architecture, le modèle de données, les deux API exposées, l'intégration des services externes, la sécurité et la stratégie de test. Chaque affirmation renvoie au code du dépôt.

\subsection{Objectifs}

Le travail poursuit six objectifs :
\begin{itemize}
  \item modéliser les données dans PostgreSQL, avec des relations 1-N et N-N et des contraintes d'intégrité vérifiées par la base elle-même ;
  \item exposer les mêmes fonctions par une API REST (Django REST Framework) et par une API GraphQL (Graphene-Django) ;
  \item consommer deux API publiques : Open-Meteo, de style REST, et Countries, de style GraphQL ;
  \item protéger l'accès par jetons JWT et par des permissions fondées sur le rôle, en suivant l'OWASP API Security Top 10~\cite{owasp} ;
  \item garantir la cohérence des données par la validation à plusieurs niveaux et par les transactions ;
  \item vérifier le tout par une suite de tests automatisés et par une collection Postman.
\end{itemize}

\subsection{Périmètre}

Le TP1 porte sur le back-end seul. L'interface utilisateur relève du TP2. L'API constitue donc l'unique interface du système. Elle est exercée par Swagger UI, GraphiQL, Postman et l'administration de Django. Le dépôt contient aussi une part d'industrialisation : image Docker, intégration continue, journaux structurés et sauvegardes. Cette part n'est pas exigée par l'énoncé ; elle prépare le déploiement du TP2.
